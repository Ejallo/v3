# VVdigital landing (v3)

Draft landing page for VVdigital: Astro + React + Tailwind + shadcn/ui, with a three.js hero scene.

## Commands

| Command           | Action                                  |
| :---------------- | :-------------------------------------- |
| `npm install`     | Install dependencies                    |
| `npm run dev`     | Start the dev server at localhost:4321  |
| `npm run build`   | Build the static site into `dist/`      |
| `npm run preview` | Preview the build locally               |

## Status

Draft, `noindex`. The contact form does not send yet; contacts, Impressum and Datenschutz are placeholders.
